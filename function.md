# Python Function builder assignment
The program:
-Calculates the average of three scores
- Determines if the average is passing
-displays the student's name, average, and status.

## How it works

Uses three functions.

### 'calculate_average()'
Calculates the average of three scores.

### 'get_status()'
Checks the average:
- can change what is passing and what isnt.

### 'show_results()'
Displays the student's name, average, and passing status.
